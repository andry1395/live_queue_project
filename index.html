Живая очередь: учет клиентов замены масла

Форма для механиков и панель администратора для контроля по подразделениям.

Выберите подразделение

Каждое подразделение ведет собственную страницу учета. Заполняйте форму после каждого обращения клиента.

Быстрый доступ к администрированию

Администратор может просматривать метрики по всем подразделениям и выгружать данные в Excel.

Открыть панель администратора

Что собираем

  • Дата визита.
  • Данные клиента (имя / авто / телефон).
  • Цель визита.
  • Статус обслуживания.
  • Причина отказа в обслуживании.
  • Комментарий, если причина нестандартная.
  • История записей сохраняется локально (localStorage).
В дальнейшем данные можно перенести в облачную БД — структура уже подготовлена под экспорт.

Версия для локального использования. Логин администратора по умолчанию: admin / admin123.
